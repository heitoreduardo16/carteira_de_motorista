# carteira_de_motorista

Projeto desenvolvido em Java para praticar lógica de programação, utilizando `boolean`, `true` e `false` para verificar a emancipação e operadores lógicos para avaliar as condições de permissão para dirigir, com entrada de dados pelo "Scanner"
