Projeto de estudo em Java

Projeto desenvolvido para praticar lógica de programação em Java, utilizando variáveis booleanas, operadores lógicos e entrada de dados com a classe Scanner.
Conceitos praticados

- Variáveis e tipos booleanos (true e false)
- Operadores lógicos (&& e ||)
- Entrada de dados pelo teclado com Scanner
- Estruturas condicionais e regras de decisão
  
Exemplos de testes
Idade	Emancipado	Resultado lógico
15	false	false
16	true	true
17	false	false
18	false	true
